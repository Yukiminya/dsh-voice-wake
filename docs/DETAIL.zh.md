# 免提语音唤醒

保持一条麦克风输入流，把「唤醒词 + 一句话」变成 DeepSeek Harness 里的普通提问。

## 使用

1. 先在「插件」里启用**语音输入**插件并下载/准备本地语音模型。本插件通过它的本地 SenseVoice Provider 识别语音。
2. 在输入框下方打开**免提语音**开关，并允许麦克风权限。
3. 直接说「**大肥鱼来**」再接一句命令，例如「大肥鱼来，帮我看看今天的日程」。只唤醒不说命令也可以：会先回你一声「来了」，状态显示「我在听，请说指令」，下一句话会被当作命令。
4. 说完停顿两秒，录音结束、整句被识别，并作为普通提问发送到当前会话，由 DSH 正常执行。
5. 输入框下方这一行里有「应答音色」下拉、「试听」、喇叭开关和麦克风开关。打开喇叭开关后，每次听到唤醒词都会用选中的二次元音色回一声「来了」；两种音色可随时切换并试听，选择会记住。
6. 播放「来了」的约一秒内麦克风会暂停接收，避免把自己的回应当成新的指令；播放结束自动恢复。

开关状态会记在浏览器里：刷新页面后如果之前是开着的，会继续尝试打开麦克风，直到你手动关掉。

## 行为说明

- 同一时间只识别一段话；正在识别或发送时，新说的话会被忽略。
- 命令句里夹带的唤醒词会被去掉，剩下的部分作为命令。
- 只说了唤醒词时，接下来 15 秒内的下一句会被当作命令；超时后重新等待唤醒词。
- 没有唤醒词的完整句子也会被识别一次（只用于判断有没有唤醒词），并在状态栏短暂显示「刚听到」的内容。

## 依赖

- 需要启用 DSH 自带的**语音输入**插件（`@deepseek-ai/dsh-experimental-voice-input-bundle`）。未启用时开关会提示语音识别不可用。
- 首次需要准备语音模型（约 240 MB，按需下载）。未就绪时这一行会显示下载进度，并提供「下载语音模型」按钮。
- 麦克风权限只授予桌面版的主窗口，且需要安全来源（桌面版使用自己的安全协议）或环回地址。
- 开关显示在会话输入框这一行。全新的空会话使用居中的新会话输入框，开关则显示在输入框上方「工作区 / 模式」那一行的右侧；命令仍会发送到这个会话。

## 隐私与限制

- 音频只发给本机的 DeepSeek Harness 做识别，不会写入会话；只有识别出的文字成为普通提问。
- 应答音色是预生成的本地音频包（用 sherpa-onnx 跑二次元角色 VITS 模型合成「来了」，22.05 kHz WAV，随插件打包），播放时不联网、不调用系统语音；本插件不朗读 DSH 的回复文字。
- 音色取自 k2-fsa 发布的社区 VITS 模型 `vits-zh-hf-theresa`（由原神 / 崩坏3 语音训练并转换为 onnx），仅用于本机个人使用；插件只携带两段「来了」音频，不包含模型文件。
- 唤醒词单独说时等待约 1 秒就结束识别并回应；进入等待命令状态后，命令句仍按两秒静音结束。
- 识别是整段式的，不是流式：没有实时字幕。
- 环境噪声可能误触发一句话；在很吵的环境里建议每次都说唤醒词，或者直接关掉开关。
- 本插件不新增 Host 服务，采集、播放和状态全部在浏览器端。
